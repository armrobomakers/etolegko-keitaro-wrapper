# Keitaro Wrapper

Небольшое FastAPI-приложение для создания тестовых кампаний Keitaro и безопасного редактирования офферов в существующих потоках.

При разработке сверялись с [Keitaro Admin API Reference](https://admin-api.docs.keitaro.io/) и официальным [руководством по Admin API](https://docs.keitaro.io/en/development/admin-api.html).

## Возможности

- Загружает домены, группы кампаний, источники трафика и офферы из Admin API.
- Создаёт кампанию с alias/name по шаблону `test_ryzhkov_<название>`; GEO принимает один или несколько кодов страны через запятую.
- Сначала создаёт кампанию в состоянии `disabled`, затем добавляет GEO-поток редиректа на Google и default-поток выбранного оффера. Включает кампанию только после успешного создания обоих потоков.
- Если сборка потоков завершается ошибкой, кампания остаётся выключенной. При неопределённом результате запроса включения приложение пытается выключить её через API; если и это не удаётся, журнал честно помечает состояние как неизвестное. Автоматического удаления объектов нет.
- Редактирует только потоки схемы `landings` со списком офферов. Изменения добавления/удаления сначала остаются в локальном черновике: удалённая строка получает 0% и может быть восстановлена, а `CANCEL` сбрасывает изменения.
- `PUSH TO KT` отправляет только итоговый список `offers`, не перезаписывая фильтры и прочие настройки потока. Доли активных офферов распределяются равномерно целыми процентами и в сумме дают 100%; остаток добавляется последней строке. Нельзя сохранить пустой список.
- Проверяет версию списка офферов перед записью, перечитывает поток после PUT и ведёт безопасный локальный журнал операций.

## Требования

- Python 3.10+
- Keitaro Admin API с доступными эндпоинтами campaigns, streams, offers, domains, groups, traffic_sources, streams_actions и stream_filters.

## Установка и запуск (Windows PowerShell)

Из каталога проекта:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` внесите API-ключ из панели Keitaro. Пароль от панели и API-ключ не должны попадать в исходники, Git, скриншоты или сообщения. `.env` и локальная БД исключены из Git.

Примените миграции и запустите приложение:

```powershell
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Интерфейс/API привязаны к localhost по умолчанию. Не публикуйте приложение в интернет без отдельной аутентификации и HTTPS.

## Миграции

- Применить: `alembic upgrade head`
- Показать текущую ревизию: `alembic current`
- Откатить одну ревизию: `alembic downgrade -1`

SQLite-файл создаётся локально в `data/keitaro_wrapper.sqlite3` и не коммитится.

## Модель маршрутизации

Первый поток имеет тип `regular`, GEO-фильтр стран в режиме `accept` и HTTP redirect на `https://www.google.com/`. GEO может содержать несколько ISO-кодов; они передаются единым списком в фильтр страны. Второй поток имеет тип `default` и направляет 100% потока в выбранный offer ID. Справочные значения GEO-фильтра и HTTP-действия выбираются из API (`stream_filters`, `streams_actions`); при нестандартном ключе redirect можно задать `KEITARO_REDIRECT_ACTION`.

Операция создания принимает `Idempotency-Key`. Повтор запроса с тем же ключом возвращает уже сохранённый результат или сообщает о незавершённой/ошибочной операции, чтобы случайный двойной клик не создал вторую кампанию.

## API

- `GET /api/health` — состояние конфигурации, без вывода секретов.
- `GET /api/catalog` — домены, группы, источники, офферы.
- `GET /api/campaigns` и `GET /api/campaigns/{id}/streams` — кампании и потоки.
- `POST /api/campaigns` — создать кампанию; обязателен `Idempotency-Key`.
- `POST /api/campaigns/{campaign_id}/streams/{stream_id}/offers/push` — сохранить список `offer_ids` с оптимистической проверкой `expected_version`.
- `GET /api/operations` — последние безопасные записи журнала.

## Важные ограничения

- Приложение не добавляет фильтры по user-agent, IP-репутации, ботам или модераторам. GEO-переадресация реализована буквально по тестовому ТЗ.
- Перед реальным запуском проверьте домен, группу, источник, GEO-код и тестовый offer в интерфейсе. Keitaro API может содержать специфичные для инсталляции action keys.
- По скриншотам ТЗ реализованы множественный GEO и поиск оффера с автодополнением. По видеодемо редактор показывает активные/удалённые строки, позволяет вернуть удалённый оффер, распределяет доли в черновике и сохраняет их только отдельным `PUSH TO KT`; `CANCEL` отбрасывает черновик.
